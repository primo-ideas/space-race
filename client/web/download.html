One file to run, nothing to install: unpack it and start star-racer-client. It plays on the same server as this page, with a gamepad, a keyboard or both. The builds are not signed: Windows asks before running it the first time ("More info", then "Run anyway"), and on macOS it opens from a right click, "Open". Linux needs ALSA and udev, which every desktop has.
